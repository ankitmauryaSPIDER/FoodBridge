FOODBRIDGE - START HERE (WINDOWS)

1. Install Docker Desktop: https://www.docker.com/products/docker-desktop/
2. Open Docker Desktop and wait until its engine is running.
3. Extract this ZIP to a normal folder, such as C:\Projects\FoodBridge.
4. Double-click start-windows.bat.
5. Wait for the first build. Then visit http://localhost:5173.
6. Keep the black startup window open while using the app.
7. To stop the app, press Ctrl+C in that window or run stop-windows.bat.
